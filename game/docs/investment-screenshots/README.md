# 단골·노트·투자 안내 실제 화면

2026-10-20, 승인된 수정 v2 앱의 새 OpenGL 캡처다. 가로1280×800/세로390×844 각103장, 전체206장 중 새40장을 원본 그대로 공개한다. 전체 PNG 크기·SHA256은 [manifest.json](manifest.json)에 보관한다. [독립 검증 증거](../../../evidence/investment-native-v2-20261020.json).
