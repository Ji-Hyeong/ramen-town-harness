# 증축·복수 메뉴 실제 화면

2026-10-16 새 OpenGL QA 실행에서 만든22장입니다. 합성 시험 저장을 사용하며 정상 플레이 저장을 읽거나 자동 실행하지 않았습니다. 전체146장의 실제 크기·SHA256은 [manifest.json](manifest.json), 기능·이행·배치·실제 종료와 한계는 [검증 기록](../../VERIFICATION.md)에 있습니다. 시안이나 CPU 합성이 아닙니다.

| 번호 | 흐름 |
| --- | --- |
| 62–64 | 등급 잠금 → 비용/환불 안내와 두 번 확인 → 실제 12석·네 테이블 |
| 65–66 | 개발과 별도로 고정한 두 판매 메뉴 → 공유 주방 예측/공헌이익 |
| 67–70 | 가속한 영업 장면 → 실제 정산 → 메뉴별 판매/대기/이익 → 재시작 |
| 71–72 | 실제 쓰기 충돌로 저장 실패 → 수동 저장 복구/재시작 |

각 흐름에 desktop(1280×800)과 portrait(390×844)가 있습니다. 게임 시간을 QA API로 앞당겨 정산을 검사하며, 중간 영업 캡처는 QA가 화면 처리 시간을 정지한 장면입니다. iPhone 실기기와 장기 플레이 감은 검증하지 않았습니다.
