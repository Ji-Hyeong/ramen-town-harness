# 요약에서 상세로 들어가는 조작

## 카드 전체가 열리는 곳

개발 화면의 육수·타레·향미유·면·토핑·익힘 카드는 현재 선택을 요약한다. 재료 아이콘, 솟은 테두리와 오른쪽의 그려진 화살표가 눌러서 열 수 있음을 표시한다. **카드의 제목·아이콘·화살표 어느 곳을 눌러도 같은 상세가 열린다.** 화살표는 글꼴 문자가 아니며 열린 상태에서는 위쪽으로 바뀐다.

카드를 열면 재료 선택과 긴 설명을 보고, 육수·면 카드에서는 관련 공법도 선택한다. 맛 실험대 역시 요약에서 열어 전체 맛 막대·궁합·이전 시제품과의 차이를 본다. 이름·개정 관리는 재료 선택 다음으로 옮겼고, 하단 시식 버튼은 계속 고정했다.

연구 지도는 여덟 개의 짧은 주제 카드로 시작한다. 카드를 열어 조건·재료 출처를 읽은 뒤 별도의 목표 선택을 한다. 카드를 여는 것과 목표를 채택하는 것은 다른 동작이다. 이번 실험 카드도 제목과 화살표가 상세 입구이며, 재료 부족 경고와 재료 찾기 버튼은 접힌 바깥에 남긴다. 같은 데이터를 새로 그려도 현재 열어 둔 지도 카드를 유지한다.

## 손가락에 보이는 반응

- 누르고 있는 동안 색·테두리와 포커스 표시가 변한다. 눌림을 표현하기 위해 실제 터치 영역을 이동하거나 흔들지 않는다.
- 탭·카드 열기·목표 선택·가격·저장·영업 등 확정한 버튼 입력에는 짧은 국소 링이 나온다. 동적으로 새로 만들어지는 버튼도 같은 경로로 등록한다.
- 재료 투입과 시식 완성은 기존의 더 큰 아이콘·조각·문구 연출을 유지한다. 작은 입력 확인과 실제 결과 연출을 구분한다.
- 스크롤로 취소한 누르기에는 클릭 링이나 확정 효과가 나오지 않는다. 화면이 움직이는 것으로 드래그를 표현한다. 비활성 버튼에도 가짜 성공 효과를 주지 않는다.
- 입력 후 목록이 다시 만들어지거나 누른 버튼이 사라져도 효과는 **처음 눌렀던 위치**에서 나온다. 시식 시작이 버튼을 비활성화해도 실제 눌림 확인은 빠지지 않는다.

공통 효과는 입력을 가로채거나 돈·점수·기록을 바꾸지 않는다. 열기·접기는 화면 상태만 바꾼다. 숫자나 설명을 삭제해 스크롤을 줄이는 대신, 현재 선택 요약 뒤로 정보를 옮겼다. 진동·효과음 설정이나 별도 보상 시스템은 이번에 추가하지 않았다.

## 검증과 역할

Claude가 재사용 펼침 카드·연구 지도 상세 구조·컴포넌트 시험을 작성했다. Codex가 재료/공법/맛 화면 연결, 모든 동적 버튼을 관찰하는 효과 경로, 실제 포인터·네이티브 터치 검증을 담당했다. 마지막 검증 결과와 실제 렌더링 여부는 [검증 기록](../VERIFICATION.md), 범위와 편집 소유권은 [계약](../../tasks/ui-depth-feedback-v1.md)에 구분한다. iPhone 설치와 실제 사용감 검증은 사용자 요청으로 연기했다.
