# 직접 담아서 발견하는 궁합과 간결한 개발 화면

처음 보는 레시피는 궁합을 알려주지 않는다. 상세보기나 그릇 비교는 읽기 전용이며, 실제로 ‘담기’를 눌러 성공한 조합에서 궁합을 발견한다. 시식까지 기다려야 공개되는 규칙이 아니다. 직접 개발한 육수와 면이 모두 준비되지 않은 시작 화면의 기본 재료는 실험한 것으로 치지 않는다.

## 플레이 흐름

1. 재료 목록에서는 그림·가격·준비 시간을 본다. 재료 상세는 큰 음식 그림과 핵심 수치를 먼저 보여 주고, 설명은 ‘재료 특성’을 눌러 펼친다.
2. ‘그릇 비교’는 실제로 바뀔 음식 모습과 원가·시간 차이를 보여 준다. 미시도 조합에는 ‘궁합 미확인’만 표시한다. 궁합 문장·합계·좋고 나쁨·단골 예상 점수로 미리 정답을 드러내지 않는다. 재료 자체의 성질과 풍미 수치는 계속 볼 수 있다.
3. ‘그릇에 담기’가 성공하면 짧은 발견 효과와 함께 조합을 기억한다. 편집 화면의 궁합 버튼으로 좋은 궁합과 아쉬운 궁합의 이유를 확인한다. 특별한 궁합 효과가 없는 조합도 미시도와 구별한다. 선택만으로 시식비·샘플을 쓰거나 기록·보상을 받지는 않는다.
4. 완성 육수·면의 비교는 현재/후보 그림과 원가·시간 차이가 먼저 보인다. 전체 배합과 풍미 변화는 펼쳐서 본다. 배합 개량은 작성 중인 개발실 배합을 바꾼다는 안내를 유지한다.
5. 면 원재료 선택지는 그림·이름·비용을 중심으로 정리했고 설명은 별도로 펼친다. 육수 공법은 한 줄의 선택지와 펼치는 안내로 나눈다. 시식 결과의 기본 화면은 단골 초상·점수·짧은 평을 중심으로 두고 전체 이유는 상세에 남긴다.

발견은 자동 저장한다. 실패하면 현재 실행 안에서만 기억된 상태임을 알리고, 직접 저장을 다시 시도할 수 있다. 성공한 재시도는 이미 열린 화면의 저장 실패 안내도 지운다. 시식 노트를 지워도 확인한 궁합은 잊지 않는다.

## 무엇을 같은 실험으로 보는가

육수·면의 실제 원재료 배합, 제조 방식, 간·향미유, 익힘, 토핑 종류와 반복 분량을 포함한다. 같은 토핑의 표시 순서, 이름이나 판매가만 바꾸는 것은 새 궁합 실험이 아니다. 이미 확인한 조합은 다음 비교에서도 결과를 볼 수 있다. 무료 선택으로 공개하는 것은 사용자의 확정 요구이며, 유료 시식은 별도로 실제 단골 평가·불변 기록·연구 증빙을 만든다.

저장18은 정규 레시피의 식별 키만 보관한다. 기존1~17 저장의 돈·날짜·제작품·시식 기록·점수·진행은 보존하고, 실제 시식 증빙에서만 과거 지식을 채운다. 미시도 초안이나 기본값으로 발견을 소급 지급하지 않는다. 첫 저장 시 기존 버전 원본을 별도 보관한다.

실험800개 이후 새 발견을 조용히 무시하던 초기 구현은 독립 검토에서 거절하고 제거했다. 저장의 기존2MiB 한도는 유지하며, 초과할 때에는 임시 파일을 열기 전에 명시적으로 실패해 기존 저장·백업을 보존한다. 지식을 자동으로 버리거나 점수 계산·재료 공급 규칙을 바꾸지 않는다.

## 구현과 검증 경계

Claude Code는 발견 판정·저장18 이행·관련 시험·저장 용량 보호를 구현했다. Codex는 화면과 컨트롤러 연결, 수정 요청, 실제 실행·입력·스크린샷·저장 호환의 독립 검증을 담당했다. 두 에이전트는 같은 저장소를 동시에 수정하지 않았다. Claude는 파일 도구만 사용했고 테스트 실행은 Codex가 수행했다.

Mac의 실제 렌더러 캡처와 손가락 이벤트 검사는 물리 iPhone의 최종 조작·접근성 수락이나6~10시간의 재미 검증을 대신하지 않는다. iPhone에 설치된0.15에는 이번 변경과 앞선 원재료 육수·제면 개발이 아직 포함되지 않는다. 이번 작업에서는 기기 설치를 하지 않는다. 실제 증거는 [화면 점검 기록](uiux-reset/recipe-knowledge-v1/README.md)과 저장소 루트 `evidence/recipe-knowledge-ui-v1.json`에 남긴다.

최종359소스와 같은 패키지에서 발견4,138개·기존129테스트59,458개·비교373개·제면276개·육수226개 검사를 통과했다. 실제 Mac 화면은 새 흐름1,123개·제면291개·육수235개·기존 편집528개·비교407개,146장 캡처로 확인했다. 작은 화면 배치513개·손가락 이벤트49개·QA 도구23개도 통과했다. 수락 실행 종료0·엔진 오류0·실행 후 공식 엔진 엄격 서명 검사0이며, 모든 캡처를 수동으로 열어 검토했다는 뜻은 아니다.
