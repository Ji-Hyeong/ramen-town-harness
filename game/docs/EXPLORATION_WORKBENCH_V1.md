# 재료 탐색에서 메뉴 개발까지

2026-10-25. 메뉴 개발에서 채택한 남색 프레임·크림 종이·청록 선택·금색 확정
버튼과 Pretendard 글꼴을 탐색에 이어 씁니다. 새 지역·재료·가격·저장 형식은
추가하지 않습니다. 실제 검증 범위는 [현재 화면](uiux-reset/exploration-workbench-v1/)
및 [디자인 검토](../../design-qa.md)에 기록합니다.

## 플레이 흐름

1. 장터·항구·산골 중 지역을 고릅니다. 지역 이동 자체는 비용이 없습니다.
2. 공급처 발견과 연구 재료 채집 중 목적을 고릅니다. 공급처는 영구 개방이며
   연구 재료는 시제품 완성 때 넣은 분량만큼 소모합니다. 각 재료의 실제 보관량,
   출발 비용, 잠긴 이유를 먼저 확인합니다. 재료 카드를 누르면 상세를 봅니다.
3. 금색 출발 버튼을 누릅니다. 모든 지역·목적을 합쳐 하루 한 번입니다.
4. 이동이 끝나면 만남의 선택지를 누릅니다. 청록색으로 표시할 뿐 아직 돈은
   쓰지 않습니다. 하단의 추가 비용을 확인하고 금색 버튼으로 확정합니다.
5. 두 번째 선택 뒤에도 재료가 자동 지급되지 않습니다. 직접 수령합니다.
6. 수령 완료에서 해당 재료로 개발하기를 누르면 실제 메뉴 개발의 재료 상세를
   엽니다. 작성하던 초안은 유지하며 자동 장착·시식·추가 결제는 없습니다.

이동·사건 중에는 목적지가 고정되고 쓰지 않는 지역·목적 탭을 접어 선택 공간을
확보합니다. 포기는 환불·그날 출발 기회 복구가 없음을 확인한 뒤 확정합니다.
돌아가기와 포기는 다릅니다. 가게로 돌아가도 진행 중인 탐색은 저장해 유지합니다.

## 변하지 않는 규칙

장터 연구 채집은 기존 공급처 두 곳을 찾은 뒤 출발 1,000원, 2개는 추가 0원,
3개는 추가 300원입니다. 항구 연구 채집은 랭크2와 항구 공급처 두 곳이 필요하고,
출발 1,200원, 1개는 추가 0원, 3개는 추가 600원입니다. 보관 한도는 각20개입니다.
산골에는 현재 반복 연구 채집이 없으며 공급처 발견만 열립니다.

공급처 발견은 장터/항구/산골의 기존 랭크1/2/3과 출발3,000/6,000/10,000원,
각 사건의 실제 추가 비용을 따릅니다. 모두 발견했거나 오늘 출발했거나 자금이
모자라면 출발할 수 없습니다. 영업·시식 준비·훈련·심사 잠금도 기존대로입니다.

## 구현 경계

`exploration_workbench.gd`는 지역·목적·강조한 선택지·상세·스크롤만 소유합니다.
실제 변경은 `main.gd`의 기존 출발/선택/수령/포기 핸들러를 호출합니다. 새 화면은
탐색 탭의 구형 서랍을 대신 표시하며 숨겨진 구형 노드를 현재 화면 증거로 쓰지 않습니다.
개발 연결은 `bowl_workbench.gd`의 읽기 전용 `reveal_ingredient`를 사용합니다.

실제 버튼에는 기존 전체 클릭 피드백이 적용됩니다. 스와이프는 클릭을 확정하지
않으며 상세 복귀 스크롤은 컨테이너 재배치 뒤 복원합니다. 저장 실패는 상단의
안내에서 전체 내용을 열어 확인할 수 있습니다. 준비·검증은 격리된 시험 저장만
사용하며 이번 버전의 실물 iPhone 사용감·접근성·재미 수용을 주장하지 않습니다.
