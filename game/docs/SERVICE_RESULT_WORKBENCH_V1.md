# 팔린 라멘과 영업 결과 읽기

채택한3번 시안의 실제 프레임·음식·목재 배경·글꼴을 영업 결과에 이어 씁니다.
[실제 화면과 전후 비교](uiux-reset/service-result-v1/)에서 확인할 수 있습니다.

## 조작

1. 영업을 끝까지 마치면 `오늘 남긴 돈`, 완료 주문, 매출을 먼저 보여 줍니다.
   오늘 남긴 돈은 매출에서 재료비와 하루 운영비를 뺀 실제 정산 금액입니다.
2. 음식 그림과 판매량이 있는 카드 전체를 누르면 그 메뉴의 판매 상세를 엽니다.
   당시 팔린 그릇·판매가·매출·재료비·손님별 완료 주문을 확인합니다.
   메뉴에서 재료비만 뺀 금액과 전체 영업의 순이익은 다릅니다.
   공통 운영비는 전체 결과에서 한 번 차감합니다.
3. `손님과 대기`에서 실제 영업 직후 만족도와 돌아간 손님 수를 봅니다.
   만족도는 메뉴 시식 점수와 다릅니다. 완료 주문이 없으면 집계 없음입니다.
   두 메뉴 영업의 평균 대기는 실제 완료 주문의 대기 합계로 계산합니다.
4. `비용 영수증`에서 매출·재료비·운영비·순이익·정산 직후 자금을 봅니다.
   정산 직후 자금은 당시 기록이며 이후 시식·구매로 바뀌지 않습니다.
5. 상단의 저장 상태를 누르면 전체 영수증과 저장 안내를 읽습니다.
   저장 실패 때는 닫으면 잃을 수 있음을 표시하고 전체 오류에 도달할 수 있습니다.
6. `가게로`는 결과를 닫습니다. `메뉴 개발`은 작성하던 초안을 유지해 개발로
   돌아갑니다. 판매한 메뉴를 자동으로 초안에 덮어쓰지 않습니다.
7. 기존 영업 탭 상단의 `N일차 영업 결과 보기`로 다시 엽니다. 다시 보기·상세·
   뒤로가기는 추가 정산·경험·돈을 만들지 않습니다.

## 기록의 범위

이전 단일 메뉴 영수증에는 그릇의 전체 구성과 영업 직후 만족도·이탈 수가 없습니다.
같은 실행에서 막 끝난 영업은 실제 판매 스냅샷을 쓰고, 재시작 뒤에는 없는 정보를
만들어 내거나 현재 초안 그림을 대신 보여 주지 않습니다. 확장 영업의 저장된
메뉴별 구성·완료 주문·대기는 재시작 뒤에도 해당 영수증 그대로 볼 수 있습니다.
만족도·돌아간 손님 수는 재시작 뒤 생략하며 그 이유를 안내합니다.

새 주문·점수·돈·저장 형식·그림·폰트는 추가하지 않았습니다. 도중 중단은 정산하지
않는 기존 규칙을 유지합니다. 아이폰 설치·실물 터치·사람의 재미 평가는 별도입니다.
현재 검증 범위는 [디자인 QA](../../design-qa.md)에 기록합니다.
