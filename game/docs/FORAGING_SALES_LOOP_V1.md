# 파밍한 메뉴를 가게에 내보기

2026-10-30 개발본. 파밍 연구 방향의 상세에서 기존 ‘시식 기록이 있어요’ 문장을
그림이 있는 클릭 카드 하나로 바꾼다. 아직 시식하지 않은 방향에는 카드가 없고,
시식·판매 메뉴·최근 완료 영업의 실제 상태에 따라 다음 단계를 보여 준다.
**승인한 v3의 실제 화면/거래 검사는647개 통과했지만 종료 후 자원 정리 경고가
남아 수용·병합하지 않았다. 자세한 재실행은 Mac 잠금 해제를 기다린다.**

| 확인한 사실 | 카드의 짧은 제목 |
|---|---|
| 해당 방향의 유료 시식은 있지만 다른 메뉴를 판매 중 | 판매 메뉴 고르기 |
| 해당 방향의 시식 메뉴가 실제 판매 목록에 있음 | 영업으로 확인하기 |
| 최근 완료 영업에서 그 메뉴를 실제로 판매 | 최근 영업 · N그릇 |

카드에는 실제 메뉴 이름·버전과 ‘영업 준비’를 함께 표시한다. 누르면 기존 판매
준비 화면만 연다. 메뉴를 대신 고르거나 배합을 불러오거나 영업을 시작하지 않는다.
기존 음식 그림·크림/남색/청록 카드·화살표·눌림·전체 면적 스크롤을 재사용한다.
상세가 열린 채 판매 목록/완료 영업만 바뀌어도 표시가 갱신된다.

## 어떤 판매를 세는가

초안, 예측, 진행 중 주문과 시식은 판매 실적이 아니다. 최근 정산의 실제 완료
수량을 쓰며, 두 메뉴를 같이 팔아도 해당 방향에 맞는 한 메뉴의 수량만 보여 준다.
두 메뉴가 모두 같은 방향이면 더 많이 팔린 메뉴 하나를 표시하고 동률은 기록
번호가 큰 메뉴다. 두 그릇을 합쳐 가짜 메뉴나 전체 손님 수로 표시하지 않는다.

증축 후 영수증은 당시 메뉴별 구성·번호·이름·버전을 보존하므로 원래 노트를
삭제하거나 나중에 배합을 바꿔도 실제로 팔았던 메뉴를 확인할 수 있다.
증축 전 기존 단일 메뉴 영수증에는 구성/번호가 없다. 이 경우 남아 있는 유료
시식 원본의 이름·버전·시식 날짜·가격·매출·완료 수량·재료비가 모두 맞는 단 하나의
기록만 연결한다. 원본 삭제, 이후 다시 만든 이름, 모순되거나 여러 개인 근거는
판매 실적이 될 수 없다. 현재 초안으로 빈 정보를 채우지 않는다.

표시는 **최근 영업**에 대한 읽기 전용 안내다. 영구 달성, 새 손님 의뢰 수락,
상금/점수/버프가 아니며 이후 다른 영업을 하면 그 새 보고에 맞춰 달라진다.
본편의 한정 판매 의뢰나 골목 시설을 완료한 것으로 세지 않는다.
