## 판매량만으로는 놓치는 차이

다음 대기는 실제 완료 주문이 기록한 게임 속 시간이며 현실 플레이 시간이 아니다.

증가를 확인한 수치가 아니다.

직원이 불필요하다는 결론으로 일반화하지 않는다.

## 다음 개선에 적용할 판단

경험치 요구량이나 시설 가격을 바로 높이지 않는다. 직원의 성장은 실제로
해결한 운영 문제와 연결하는 편이 낫다. 특히 홀 직원에게 이 표본에서 관측되지
않은 ‘판매 증가’를 일률적으로 요구하면 잘못된 목표가 된다. 다음 묶음에서는
기존 기본 서버에게 **새 메뉴 두 종류를 함께 운영하는 역할 도전**을 먼저
검증한다. 새 구성의 실제 시식, 두 메뉴의 실제 완료 주문, 대기와 반응을 함께
본다. 정확한 조건과 보상은 별도 계약·달성 가능성·저장 호환 검사로 확정한다.
