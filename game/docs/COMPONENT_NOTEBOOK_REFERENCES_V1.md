중인 항목을 제거한 시험은 정상 파서가 거부하고 대상 상태를 바꾸지 않았다.

## 후속 구현 방향

권장안은 자주 쓰는 작업용 노트와 이미 제조한 배합의 소유 증빙을 구분하는 것이다.
작업용 목록을 정리해도 과거 메뉴·개정 비교·판매/사연 증빙은 그대로 읽히고,
이미 만든 배합을 다시 꺼내는 비용·절차가 명확해야 한다. 랭크에 따른 작업 공간
확장은 이 구조 위에서 조정한다. 구체적인 용량·가격은 아직 확정하지 않았다.

후속 작업은 다음 경계를 함께 만족해야 한다.

- 기존 지원 저장의 제조 소유 증빙과 전체 메뉴 값을 이행·백업한다.
- 보관·복귀를 명시적 행동으로 만들고 실제 완료 여부를 피드백한다.
- 영업·제조·시식 중 변경을 거부하며 이미 쓰인 배합을 조용히 지우지 않는다.
- 현재 그릇·보관 후 다시 꺼낸 메뉴·오래된 비교·삭제된 기록의 최고 증빙을 확인한다.
- 목록 숫자 인덱스를 영구 식별자로 삼지 않으며 같은 화면의 선택을 안정적으로 갱신한다.
- 저장 실패·중복 누름·재시작과 화면 세 크기를 실제로 확인한다.

이 문서는 위 구조의 설계 근거다. 배합 보관·복귀·용량 확장이나 새 저장 형식을
이미 구현/승인했다는 뜻은 아니다. 장터·가독성 통합 PR61은 먼저 별도 실제 화면
검증을 끝내고, 배합 노트 개선은 그 뒤의 독립 작업으로 진행한다.
