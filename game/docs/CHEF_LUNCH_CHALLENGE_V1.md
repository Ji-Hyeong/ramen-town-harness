# 요리사의 첫 성장 · 점심 라멘 개발

가게 정보 → 직원·가게 → 요리사 카드에서 무료로 도전을 수락합니다.
구성을 바꿔 새로 시식한 메뉴를 한 종류만 판매하고 실제 영업을 끝까지 마칩니다.
영업 결과의 요리사 버튼에서 조건별 실제 결과와 성장 확인으로 이어집니다.

| 한 영업에서 달성할 조건 | 기준 |
| --- | --- |
| 새 메뉴 개발 | 수락 후 새 시식 기록, 수락 당시보다 재료·토핑·공법 변경 |
| 기본 조리 시간 | 100초 이하, 직원 효과 적용 전 |
| 판매 가격 | 9,500원 이하 |
| 완료 주문 | 5그릇 이상 |
| 평균 대기 | 완료 주문의 실제 자리 대기 + 음식 대기 평균 120초 이하 |
| 평균 만족도 | 완료 주문의 실제 반응 3/5 이상 |

가격만 바꾸거나 이전 시식 기록을 그대로 판매하면 새 개발 조건을 만족하지 않습니다.
중단한 영업, 예측 화면, 분석용 빠른 정산은 실적을 만들지 않습니다. 증축한 가게도
판매 한 종류로 도전할 수 있으며 두 종류 영업은 그대로 가능하지만 이 도전에 집계하지 않습니다.

첫 달성 기록은 불변 스냅샷으로 남습니다. 뒤에 다른 메뉴를 팔거나 노트를 정리해도
사라지지 않습니다. 성장 확인은 한 번만 가능하며, 다음 영업부터 요리사의 조리 시간이
5% 줄어듭니다. 보조 직원 효과를 먼저 올림한 뒤 95%를 적용하고 다시 올림합니다.
예를 들어 보조 직원이 없는 도전 메뉴의 78초는 75초가 됩니다. 자금, 일당, 맛 점수,
서빙 시간과 직원 수에는 보너스가 없습니다. 현재 범위는 첫 도전 한 단계입니다.

## 저장과 검증

수락, 실제 영업 정산, 성장 확인은 기존 자동 저장 경로를 사용합니다. 저장에 실패하면
메모리 변화와 이전 디스크 파일을 구분해 경고하며, 보상 재지급 없이 수동 저장으로
복구할 수 있습니다. 성장 연출은 이미 반영한 효과를 보여 주며 추가 보상을 만들지 않습니다.
저장 형식14는 수락·불변 실적·습득일을 엄격하게 검사한 뒤 한 번에 불러옵니다.
형식1~13은 소급 보상 없이 도전 대기로 이행하고, 첫 저장 전에 기존 파일을 버전별로
보존합니다. 일반 플레이 저장은 개발 검증에 접근하지 않았습니다.

테스트는 공개 게임 동작으로 레시피·랭크·직원·증축을 준비하고 실제 주문 상태를
끝까지 진행합니다. 전후 효과, 중복 수령 거부, 영업 중단, 두 메뉴 제외, 옛 저장 이행,
손상 저장 거부, 디스크 실패·복구·재시작을 확인합니다. 실제 렌더링과 포인터 검사,
시안·이전 화면·최종 화면 비교는 아래 기록에 남깁니다. 자동 검사는 장시간 플레이의
재미나 본편 분량, 아이폰에서의 사용성을 입증하지 않습니다. Claude와 아이폰 작업은 제외했습니다.
