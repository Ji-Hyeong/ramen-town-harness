# 그릇에서 시작하는 메뉴 실험

2026-10-23 · Codex 단독 구현. [작업 계약](../../tasks/discovery-workbench-v1.md).

## 실제로 하는 일

개발 첫 화면에 현재 조합의 큰 도트 그릇·실제 원가/준비 시간·풍미가 나온다.
그릇은 기존48×32 동적 그림을 정수4배로 표시하며, 여러 토핑 분량·국물·면·공법을
계속 실제 구성에서 읽는다. 고정 완성 그림으로 다른 재료를 그려 넣지 않는다.
매장 안 작은 서비스용 그릇은 바꾸지 않는다.

상단 작업 카드는 아이콘과 화살표를 포함한 전체가 눌린다. 펼치면 기존8개 작업과
소리 설정·판매 메뉴 안내가 나온다. 작업을 고르면 다시 접힌다. 재료·공법 선택은
기존 상세 카드와 스크롤을 유지하며, 연구 조건과 자세한 맛 계산은 재료 뒤에 있다.

## 파밍에서 여는 세 방향

| 방향 | 실제 조건 | 재료 출처 |
| --- | --- | --- |
| 유자 맑은탕 | 유자 껍질, 진함5이하·향6이상 | 새벽 장터 유자 수레 |
| 참깨 진국 | 볶은 참깨유, 진함8이상·향6이상 | 새벽 장터 볶음 양념 노점 |
| 정어리 가리비탕 | 구운 정어리 육수+가리비 고명, 염도7이하 | 아침 항구 채집 |

정해진 완성 레시피3개를 추가한 것이 아니다. 각 방향을 만족하는 조합은 여러 개이며
같은 재료로도 원가·시간·손님 반응이 달라진다. 방향 선택은 현재 초안·돈·기록을
바꾸지 않는다. 재료 고르기는 기존 선택 화면, 재료 찾기는 실제 탐색 화면으로 이동한다.
이동만으로 출발하거나 재료가 생기지 않는다. 목적에 맞는 준비 시간인지도 직접 비교한다.

재료를 골라 조건을 맞춘 상태와 시식을 마친 상태를 구분한다. 기존 유료 시제품이
성공적으로 완성되어 노트에 남아야 시식한 방향으로 표시한다. 가격·이름만 바꾸거나
시식을 취소/거부당하거나 화면을 다시 열어서 새 발견을 만들 수 없다. 처음 기록한
방향에는 큰 완성 연출·다른 소리가 나온다. 노트에 남은 기록을 기준으로 하므로
증빙을 삭제하면 시식 여부가 사라질 수 있다. 영구 수집 원장이나 새 보상은 없다.

시식 결과는 실제 그릇·핵심 수치·새 방향을 먼저 보여준다. 긴 재료/공법 영수증은
아이콘·화살표가 있는 상세로 들어가고, 다음 한 그릇 버튼은 초안을 유지한 채
다시 실험 방향을 고르는 화면을 연다. 기존 손님별 시식평·비교·개정 기능도 유지한다.

## 반응과 소리

확정 탭, 재료 투입, 국물, 면, 담음새, 일반 완성, 새 방향, 시식 거부를 구분한 짧은
로컬 효과음8개를 사용한다. 원본은 프로젝트의 `tools/generate_action_audio.py`로
직접 합성한 PCM이며 외부 녹음·다운로드·유료 서비스가 없다. 원본 코드와 음원은
같은 저장소 라이선스/권리 조건을 따른다. 최대0.48초, 낮은 진폭·재생 음량과 유한
동시 재생 수를 사용한다. 효과음은 진행 시간·돈·점수·입력을 제어하지 않는다.

작업 메뉴의 소리 버튼은 즉시 모든 재생을 멈춘다. 설정은 **이번 실행 동안** 유지되며
게임 저장에 필드를 추가하지 않는다. 스크롤로 취소한 누르기는 확정 신호가 없어
클릭 소리·클릭 링·재료 선택을 만들지 않는다. 제작 중 편집과 중복 시식도 막는다.
효과가 실제 소모나 발견을 앞서서 성공했다고 알리지 않도록 거래 완료 뒤에 연결했다.

## 검증 상태와 범위

순수 방향55확인, 실제 유료 제작/취소/저장 복원/입력 흐름 및 현재 패키지1,896확인,
기존 실험·상세 흐름3,724확인, 항구918확인, 터치70확인, 도메인127시험/58,423확인이
실패0·종료0·엔진 오류0이다. 두 화면 전체 배치19,496확인도 같은 기준으로 통과했다. 현재161소스는 새 QA
스냅샷과 바이트가 같고 공식 엔진의 엄격 서명은 통과했다.

**현재 실제 화면 검사는 실행 승인 대기다.** 헤드리스 결과나 PNG 예상 장수를
실제 렌더링 성공으로 계산하지 않는다. 새 앱의 현재 화면을 확인한 뒤 이 절을 갱신한다.
오디오 파일·재생 신호 검사는 실제 사람이 기기에서 들은 음질/음량 수락을 대신하지 않는다.
iPhone 설치·최신 손가락 조작·성능·중단 복귀·사람의 재미/본편 길이는 별도다.
기존26개 도메인/서비스 스크립트·평가·저장 스키마13·영업 경제는 바꾸지 않았다.
