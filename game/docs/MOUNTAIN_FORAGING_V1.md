# 산골 연구 재료 · 메뉴 실험

랭크 3에서 산골의 기존 공급처 두 곳(고추기름·표고 조림)을 발견하면
탐색 → 산골 → 연구 재료 채집을 이용할 수 있습니다.

1. 출발비 1,600원을 내고 제분소 또는 산표고 화덕을 고릅니다.
2. 직접 손질 1개(추가 0원) 또는 손질 부탁 3개(추가 800원)를 확정합니다.
3. 결과에서 직접 받습니다. 받기 전까지 재료는 보관함에 들어오지 않습니다.
4. 재료 상세에서 현재 그릇과 비교하고 직접 반영합니다. 이동·비교만으로는 초안이나 돈이 바뀌지 않습니다.

모든 지역의 공급처 탐색과 채집을 합쳐 하루 한 번 출발합니다. 포기하면 이미 낸
돈과 출발 기회는 돌아오지 않습니다. 시제품이 완성될 때 면 한 분량 또는 넣은
토핑 수만큼 연구 재료를 씁니다. 준비 취소·재료 부족에는 돈과 재료를 쓰지 않습니다.
완성해 노트에 남긴 메뉴의 영업 판매에는 다시 채집할 필요가 없습니다.

| 재료 | 한 분량 | 실제 변화 |
|---|---|---|
| 산메밀면 | 원가 480원 · 준비 65초 | 향 +2, 식감 +6. 가는 면보다 비싸고 느리며, 굵은 면보다 식감은 낮지만 빠름 |
| 구운 산표고 | 원가 460원 · 준비 19초 | 진함 -1, 향 +3, 식감 +1. 중복하면 각 분량의 비용·시간·풍미·샘플을 각각 반영 |

파밍 연구 방향에 **산향 메밀탕**(산메밀면, 진함≤5·향≥6·식감≥6)과
**산표고 진국**(구운 산표고, 진함≥7·향≥7)을 추가했습니다.
여러 조합으로 달성하는 실험 조건이며 자동 레시피·추가 점수·별도 재화 보상은 없습니다.
실제 보관 중인 시식 기록으로만 달성 여부를 확인하며, ‘재료 찾기’는 해당 지역을 엽니다.

저장은 v15입니다. v1~14를 읽을 때 기존 돈·메뉴·성장·요리사 증빙을 보존하고
새 재료는 지급하지 않습니다. 처음 저장할 때 원래 버전의 파일을 별도 백업합니다.
재고 보존식, 수령·소비 증빙, 공급처 발견 날짜, 네 경로의 공통 출발일을 검사합니다.
