# 실험 목표에서 재료 탐색으로

기존 다섯 실험 방향을 재료 그림이 있는 목록으로 고른다. 상세에는 필요한
재료별 준비 상태와 실제 출처를 모아 두었다. 아직 만들지 않은 라멘의 정답
점수·궁합 조건을 미리 보여주지 않는다.

## 플레이 흐름

1. 메뉴 개발의 작업 메뉴에서 ‘파밍 연구 방향’을 연다. 영업 후 다음 행동의
   재료 탐험, 매장 운영 상세의 탐색에서도 같은 목표를 볼 수 있다.
2. 목록의 카드 전체를 눌러 상세를 읽고 목표를 선택한다. 필요한 재료가 두
   가지면 두 가지 모두 표시한다. 카드를 고르는 것만으로 재료를 넣거나
   돈을 쓰거나 탐험을 시작하지 않는다.
3. 지역의 공급처 두 곳을 찾기 전에는 **공급처 탐험 보기**로 이동한다.
   모두 찾은 뒤에는 **연구 샘플 채집 보기**로 이동한다. 실제 지역 화면에서
   비용과 선택을 검토하고 출발을 따로 확정한다.
4. 채집한 재료를 수령한 뒤 **목표 준비 확인**으로 돌아간다. 목표와 다른
   재료를 받았다면 목표 재료의 샘플이 늘어난 것으로 세지 않는다.
5. **이 재료로 실험**은 실제 재료 상세를 연다. 초안에 담기·제조·시식은
   각각 기존 화면에서 확정한다. 이미 개발한 육수·면은 실제 완성품을 연다.

## 준비 상태의 의미

공급처 발견, 연구 샘플 재고, 개발한 육수·면은 서로 다르다. 샘플을 다 써도
발견한 재료 정보와 개발 배합은 남는다. 개발품을 그릇에 담을 수 있어도
새 유료 시식에는 해당 연구 샘플이 다시 필요하므로 부족 수량을 따로 표시한다.
반복 토핑은 현재 그릇에 들어간 분량만큼 계산하며 목표의 최소 준비량은 1개다.
‘샘플 준비됨’은 이 재료 재고의 표시이며 전체 레시피나 시식 성공을 보장하지 않는다.

랭크·오늘 출발 여부·잔액·작업 중 상태·재고 한도의 기존 제한을 표시한다.
출처는 출발이 막힌 날에도 열어볼 수 있다. 출발·비용·보상·샘플 소비는 기존
게임 규칙이 다시 검사하며, 이동 직전에도 현재 상태에서 목적지를 계산한다.
실험 방향의 시식 표시는 실제로 보관된 유료 시식 기록에만 근거한다.

## 유지한 범위와 한계

새 식재료·목표 보상·경제 규칙·저장 원장을 추가하지 않았다. 저장 스키마18과
기존 도메인·서비스·원본 자산을 유지했다. 선택한 목표 자체는 기존처럼 현재
실행의 화면 선택이며 재시작 후 자동 선택을 보장하지 않는다. 준비 상태와
시식 기록은 저장된 사실로 다시 계산한다.

Claude는 읽기 전용 목표 판단·카드 화면·집중 시험을 구현했다. Codex는 기존
화면 연결·실제 유료 탐험과 시식 경로·독립 시험·화면 검토를 맡았다. 파일은
순서대로 작성했고 Claude의 보고를 통과 증거로 사용하지 않았다. 중간 수정
호출의 턴 제한 실패와 미완성 시험은 반려한 뒤 같은 작업을 명시적으로 재개했다.

실제 Mac의 가로·세로·짧은 세로 화면을 검사했다. 시험 준비에서는 기존 제조·
영업 시간을 일부 앞당겼으므로 실제 대기 연출·사람의 재미를 검증했다고 하지
않는다. iPhone 설치·최신 실기기 조작·음향·발열·6~10시간 본편 완성도는 별도다.
