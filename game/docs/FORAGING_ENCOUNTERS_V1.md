# 지역의 만남에서 다음 한 그릇으로

기존 채집에 지역별 만남을 하나씩 추가했다. 같은 지역의 두 재료 중 무엇을
얼마나 가져올지 고르고, 받은 재료를 다른 지역의 재료와 조합해 본다.
재료 종류는 기존 여섯 가지 그대로다. 정답 레시피를 자동 완성하지 않는다.

## 채집의 선택

공급처를 발견한 뒤 연구 샘플 채집에서 출발한다. 원래의 개별 재료 채집도
그대로 선택할 수 있다. 새 만남에서는 아래 두 몫 중 하나를 고른다.

| 지역 / 만남 | 첫 번째 몫 / 추가 비용 | 두 번째 몫 / 추가 비용 | 별도 출발비 |
|---|---|---|---|
| 장터 / 마감 공동구매 | 볶은 참깨유 2개 / 0원 | 유자 껍질 5개 / 900원 | 1,000원 |
| 항구 / 새벽 어획물 나눔 | 구운 정어리 육수 연구 재료 2개 / 400원 | 가리비 고명 5개 / 1,400원 | 1,200원 |
| 산골 / 제분소 공동 주문 | 산메밀 면 연구 재료 5개 / 1,800원 | 직화 산표고 2개 / 500원 | 1,600원 |

만남 선택에는 추가 비용이 없다. 두 번째 선택을 확정할 때 표시한 추가 비용만
결제하며, 마지막 **재료 받기**를 누를 때 재고가 증가한다. 연구 재료를 받아도
육수·면 완성품이 자동으로 생기지 않는다. 원재료 제조와 적용은 기존 개발
작업대에서 진행한다.

보관 한도는 재료별 20개이며 하루에 출발할 수 있는 횟수도 그대로다. 선택할
수 있는 한 가지 몫이 비용과 보관 공간을 동시에 충족해야 만남을 고를 수 있다.
재료 하나가 가득 차도 다른 몫을 받을 수 있으면 열려 있다. 같은 선택이나
수령을 반복해 돈을 두 번 내거나 재료를 두 번 받을 수 없다.

이 만남은 채집 때 고르는 고정 선택지다. 날짜별 무작위 사건·희귀 드롭·시간대
잠금이 구현된 것은 아니다. 원래 개별 재료 채집의 수량과 비용은 바꾸지 않았다.

## 지역을 연결하는 실험

메뉴 개발의 ‘파밍 연구 방향’에서 **지역 실험 / 지역 연계**로 나눠 고른다.
원래 다섯 방향에 다음 세 방향을 더했다.

- 유자 가리비탕: 장터의 유자와 항구의 가리비.
- 참깨 메밀 진국: 장터의 참깨유와 산골의 메밀.
- 정어리 산표고탕: 항구의 정어리와 산골의 직화 표고.

각 재료의 실제 공급처·샘플 재고·제조 상태를 따로 확인한다. 목표나 카테고리를
누르는 것은 열람이며 결제·출발·재료 적용이 아니다. 맛의 조건은 여러 배합으로
도달할 수 있고, 보관한 유료 시식 기록이 있을 때만 시식 완료로 표시한다.
새 보상·능력치 보너스·레시피 수집 원장은 추가하지 않았다. 목표 선택은 현재
실행의 화면 상태이며 자동으로 저장되는 영구 퀘스트가 아니다.

## 저장과 검증 범위

저장 형식은 18을 유지한다. 이전 버전에서 실제 행동으로 만든 저장 27개를
현재 코드로 읽고 다시 저장해 전체 값이 같은지 검사했다. 기존 출발·선택 중·
수령 대기·수령 완료·시식 소비·포기·오래된 이력 잘림을 포함한다. 사용자
저장은 열거나 수정하지 않았다. 한 번에 5개를 받을 수 있어 늘어날 수 있는
누적 획득·소비 한도만 조정했으며 재고·날짜·이력·소비 보존 검사는 유지한다.

Claude는 공통 채집 규칙·세 지역 사건·집중 시험을 구현했고, Codex는 지역 연계
목표·분류 화면·탐색 표시·독립 검증을 맡았다. 파일은 순서대로 작성했다.
실제 Mac 렌더링 결과와 최종 검사 수치는 아래 실행 증거에 기록한다. 준비 과정의
제조·영업 시간 일부를 앞당긴 시험이며 사람의 재미나 본편 길이 검증은 아니다.
iPhone 설치와 실기기 검증은 이번 범위에서 제외했다.
