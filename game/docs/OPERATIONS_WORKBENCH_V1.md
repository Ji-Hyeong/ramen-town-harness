# 메뉴 노트·의뢰·단골·대회·판매 화면

남아 있던 다섯 기능을 선택한 3번 시안의 원본 프레임·그릇·글꼴·버튼으로
연결합니다. 기존 개발·탐색·직원·가게 화면은 유지합니다. 이번 범위는 기존
기능의 화면과 조작이며 새 콘텐츠, 경제 밸런스, 저장 형식은 추가하지 않습니다.

![실제 노트·연구·대회 흐름](uiux-reset/remaining-workbench-ui-v1/comparisons/portrait-journey.png)

## 조작

- 메뉴 노트: 최신 메뉴 / 개정 이력 / 판매 중을 나눕니다. 이력은 한 쪽에 8개씩
  표시합니다. 그릇 카드 전체를 누르면 실제 구성·가격·시간·단골 평가와 이전
  개정본 비교를 봅니다. 상세에서 개발용으로 불러오거나 의뢰·대접 대상을 고릅니다.
  기록을 불러오면 편집 중 초안도 그 기록으로 바뀐다는 안내를 실행 버튼 위에 표시합니다.
- 기록 삭제: 상세에서 같은 삭제 버튼을 두 번 눌러야 실행합니다. 뒤로 가면
  확인을 취소합니다. 판매에 고정한 기록은 먼저 판매에서 빼야 하며, 기록을
  정리해도 이미 받은 연구·단골·대회 보상을 다시 만들지 않습니다.
- 판매: 개발·제출 대상과 판매 고정을 구분합니다. 기존 증축으로 열린 두 번째
  칸에는 첫 메뉴를 유지하며 추가합니다. 자동 판매 복귀와 실제 수요·주방 예상,
  지난 정산 결과를 연결합니다. 수요는 확정 매출이 아닙니다.
- 연구: 얼굴 카드에서 진행 상태를 먼저 봅니다. 상세에는 실제 시식 기록을
  대상으로 계산한 조건·현재 값·힌트·보상을 보여 줍니다. 초안은 제출하지 않습니다.
- 단골: 얼굴을 눌러 사연·방향·대접 조건·이전 대화·답례 기록을 봅니다. 방향은
  6초 안에 같은 선택을 다시 눌러 확정합니다. 첫 장 이후에는 새 구성과 새 영업이
  필요하며, 실제 대접을 마친 뒤 두 번째 장과 결말을 확인합니다.
- 대회: 조건과 출품료를 확인한 뒤 출품합니다. 심사 진행 중에는 조작을 막고,
  완료하면 실제 출품한 그릇·점수·상금·평가를 먼저 보여 줍니다. 잡지 제안과 이미
  게재한 기사도 실제 기록을 씁니다. 금메달 완료와 한 번만 받는 협조비를 구분합니다.
- 저장: 상단 안내에서 현재 저장 상태, 최근 작업 메시지와 자동 저장 범위를 봅니다.
  수동 저장을 실행할 수 있으며, 실패하면 경고를 유지합니다. 보상을 재지급하는
  방식으로 저장 오류를 보상하지 않습니다.

카드의 그림·제목 위에서도 밀어서 스크롤합니다. 밀기는 누름을 취소하며,
짧은 누름에는 기존 클릭·소리 피드백을 적용합니다. 목록과 상세 사이를 돌아갈 때
스크롤 위치를 보존합니다. 세로는 한 열, 넓은 화면은 두 열이며 실행 버튼은 고정합니다.

## 검증 범위

동일한 최종 패키지에서 실제 렌더링과 포인터 입력을 검사했습니다.

| 검사 | 확인 수 | 실패 | 실제 캡처 |
| --- | ---: | ---: | ---: |
| 새 화면 전체 흐름 | 1,216 | 0 | 48 |
| 기존 가게 화면 | 780 | 0 | 24 |
| 기존 개발 화면 | 524 | 0 | 30 |
| 기존 직원·성장 화면 | 772 | 0 | 30 |
| 목록 처음·비교 상세·정산 이동, 세 화면 크기 | 388 | 0 | 15 |

모든 실행은 종료 코드 0이고 엔진 오류가 없습니다. 작은 세로 화면 전체 흐름의
배치 전용 검사 538개와 기존 도메인 127개 테스트(58,423개 확인)도 통과했습니다.
배치 전용 검사는 이미지 검증에 합산하지 않습니다.

준비 상태는 실제 공개 거래로 만들었습니다. 돈·랭크·보상을 임의로 넣지 않았습니다.
영업 두 메뉴, 연구·단골 두 장·결말, 출품료·상금·잡지 협조비의 중복 수령 거부,
기록 삭제 취소·확정과 재시작을 확인했습니다. 임시 저장 경로에 빈 디렉터리를
만들어 실제 디스크 저장 실패를 재현했고, 이전 파일이 유지되는지와 수동 복구를
확인했습니다. 모든 저장은 별도 QA 경로이며 일반 플레이 저장은 접근하지 않았습니다.

선택 시안은 개발 화면입니다. 노트·의뢰의 같은 진행 상태를 이전 화면과 비교하고,
그 시안의 디자인 체계를 다른 기능으로 확장했습니다. 존재하지 않는 원본 상세
화면과 픽셀 단위로 일치한다고 주장하지 않습니다. 캡처와 자동 검사는 플레이
재미나 본편 분량을 증명하지 않으며, 아이폰 설치·실기기 확인은 이번에 하지 않았습니다.
