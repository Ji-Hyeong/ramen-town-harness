# 선택한 개발 목표를 시식 결과에서 확인하기

유자 가리비탕을 목표로 만들었는데 시식 결과에는 ‘유자 맑은탕’이 먼저 표시됐다.
두 방향을 동시에 만족할 때 목록의 앞에 있는 이름만 보여 주던 문제였다.
이제 결과의 한 줄은 선택한 목표와 **실제로 시식한 이 그릇**을 먼저 설명한다.

| 결과 표시 | 의미 |
|---|---|
| 목표 달성 | 이번 유료 시식에서 새로 확인한 방향이며 선택한 목표도 충족 |
| 목표 충족 | 보관한 이 시식 기록이 선택 목표를 충족. 새로운 발견이라는 주장은 하지 않음 |
| 더 실험 | 이번 그릇이 선택한 목표의 재료·맛 조건을 아직 충족하지 않음 |

충족한 목표는 금색, 미충족 목표는 중립 카드로 표시한다. 모두 카드 전체를
누르면 실제 시식 조건을 읽을 수 있다. 선택한 목표의 충족·미달을 먼저 보여
주고, 같은 그릇이 함께 완성한 다른 방향은 뒤에서 확인한다. 상세 조건은 이미
시식한 그릇의 관찰이며 아직 맛보지 않은 초안의 정답을 예고하는 것이 아니다.

시식 결과 화면에서 작업 메뉴 → 파밍 연구 방향으로 목표를 바꿔도 바로 갱신한다.
선택만으로 기록·재료·돈은 바뀌지 않는다. 과거의 다른 그릇이 목표를 달성했어도
현재 결과의 그릇이 맞지 않으면 ‘더 실험’이다. 재시작 후 목표를 다시 골랐을 때는
남아 있는 실제 시식 기록을 기준으로 ‘목표 충족’을 보여 준다. 목표 자체는 기존처럼
현재 실행의 화면 선택이며 새 영구 과제나 저장 필드를 만들지 않았다.

목표를 고르지 않았다면 기존의 새 방향·연구 기록·완성 방향 표시를 유지한다.
직접 시식한 기록 없이 목표를 고르거나 초안을 편집하는 것만으로 새 발견을 주지
않는다. 잘못된 목표나 손상된 기록은 성공으로 바꾸지 않고 오류를 표시한다.

Claude는 실제 기록에 대한 읽기 전용 판정과 집중 시험을 구현했다. Codex는 기존
결과 카드·상세·화면 갱신과 독립 검증을 맡았다. 경영 계산·저장18·재료·그림·
판매 결과를 바꾸지 않았다. 시험의 시작 저장은 PR46에서 완전 새 게임으로
원재료 제조·연구·승급·채집을 실제 수행하고22일 저장/재시작을 거친 복사본이다.
사용자 저장이나 예전 완제품 지급 모드가 아니다. 자동 준비와 관찰을 사람의
재미·6~10시간 플레이 검증으로 계산하지 않는다. 이번에도 iPhone 설치는 없다.
