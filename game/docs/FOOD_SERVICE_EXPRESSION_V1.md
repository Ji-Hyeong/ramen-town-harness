# 재료에 따른 음식 표현과 매장 연출 V1

실제 적용한 육수·면 배합과 향미유가 음식의 표면에 드러나도록 기존 그림의 표현을 확장한다. 원본 음식·그릇·토핑·폰트 파일은 그대로이며 새 재료나 점수 보상, 저장 항목을 추가하지 않는다.

- **국물:** 원재료의 비중과 우림 방식으로 맑기·탁도·기본색을 정한다. 타레와 실제 향미유가 색과 기름막에 반영된다. 맑은 다시마 계열, 황금빛 닭 육수, 크리미한 뼈 육수, 붉은 고추기름, 초록 파기름 등을 구별한다.
- **면:** 기존 굵기별 원본 형태를 유지하고 밀가루·간수·반죽 방식의 차이를 색에 반영한다. 모든 배합마다 완전히 다른 그림을 만든 것은 아니다. 토핑의 각 분량은 독립된 원본 레이어로 유지한다.
- **영업 중 음식:** 대기·운반·식탁의 작은 그릇에도 같은 실제 배합을 사용한다. 편집 중인 초안을 판매 중인 메뉴 대신 보여 주지 않는다.
- **매장:** 실제 조리 시작·서빙 준비·운반·식사 시작에 짧은 반응을 붙인다. 손님의 실제 평가 말풍선이 나올 때만 강조하고 나쁜 반응을 좋은 반응으로 바꾸지 않는다. 같은 상태를 계속 그려도 효과를 재발급하지 않는다.
- **확대 보기:** 세로 매장의 ‘확대’로 주방·카운터를 더 크게 본다. ‘전체’로 거리·대기 줄·외곽을 다시 확인한다. 확대 화면은 주방 중심의 일부 영역이며, 모든 좌석·줄 끝을 동시에 보여 준다는 뜻은 아니다. 확대는 배치·손님 이동·영업 시간·재화를 바꾸지 않는다.

옛 완제품 메뉴와 새 원재료 배합을 구분한다. 옛 육수와 새로 만든 면을 함께 쓸 때도 육수의 기존 표현을 유지한다. 잘못된 원재료 정보는 오류로 보고하며 성공한 것처럼 임의의 음식으로 대체하지 않는다. 궁합·손님 점수·해금 조건을 미리 알려 주는 기능은 없다.

초기 화면 검사에서는 국물이 계속 주황색으로 보였다. 새 색에 원본 텍스처가 다시 곱해지는 경로를 고쳤고, 기존 메뉴는 이전 계산을 유지했다. 이는 [Godot의 fragment COLOR 규칙](https://docs.godotengine.org/en/latest/tutorials/shaders/shader_reference/canvas_item_shader.html)에 근거한 보정이며, 실제 렌더링에서 다시 확인한다. 별도의 그림 파일을 덮어쓴 것이 아니다.

Claude가 음식의 표현 모델·레이어·셰이더·관련 시험을 구현하고 두 차례 보정했다. Codex는 실제 화면의 차이를 판정하고 색 중복 곱셈 보정, 작은 음식 연결, 매장 효과·확대, 독립 검증을 맡았다. Claude의 외부 캡처 읽기는 제한되어 재시도하거나 권한을 넓히지 않았고, 해당 시각 검토는 Codex가 수행했다. 마지막 읽기 전용 코드 검토에서 발견한 타레 중복 적용도 수정했다. 구독 사용률의 비중은 추정하지 않는다.
