# 같은 이름의 두 그릇에서 실제 배합 읽기

2026-11-01 정리. 유료 시식의 비교 상세에서 돼지뼈2분량과3분량이 모두 같은
이름으로 보이는 문제를 보완했다. 기본 결과 화면은 유지하고, 기존 두 그릇
아래에 **실제로 달라진 육수/면 배합만** 짧게 표시한다. 실제 화면은 아직 미검증이다.

- 육수는 기존 원재료 표시기를 그대로 써 `돼지뼈 ×2`와 `돼지뼈 ×3`, 실제
  우림 공법을 구분한다. 여러 원재료를 빼거나 임의로 한 분량으로 바꾸지 않는다.
- 제면은 가루·배합수·굵기·반죽/숙성을 함께 읽는다. 이름이 비슷해도 무엇을
  바꿨는지 확인할 수 있고, 기존 펼친 변경 내역에도 같은 실제 정보를 쓴다.
- 가격/토핑만 바꿨다면 원재료 설명을 추가하지 않는다. 이전 저장에 원재료
  정보가 없는 쪽은 실제 기존 이름을 보여 주며 과거 배합·분량을 만들어내지 않는다.
- 현재 초안이 아니라 이전/이번 유료 기록의 구성 복사본만 읽는다. 원본 노트를
  삭제하거나 나중에 다른 배합을 만들어도 과거 비교를 덮어쓰지 않는다.
