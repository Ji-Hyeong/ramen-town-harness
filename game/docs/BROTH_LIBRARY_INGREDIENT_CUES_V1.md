# 육수 목록에서 배합을 바로 구분하기

2026-11-02. 같은 이름의 육수라도 원재료와 분량이 다르다. 이전 목록은 냄비 그림과
짧은 제품 이름만 보여 줘서 원하는 배합을 찾으려면 비교 화면을 반복해서 열어야 했다.
작업 노트와 보관함의 각 카드에 **원재료 그림·이름·분량**을 함께 표시한다.
기존 원가·준비 시간 옆에는 실제 완성 배합의 우림 방식을 보여 준다.

같은 재료는 `다시마 ×3`처럼 묶는다. 재료 그림과 이름·분량은 한 묶음으로 줄을
바꾸므로 긴 이름도 중간에서 끊기지 않는다. 기존 원재료 그림과 글꼴을 재사용하며,
새 버튼처럼 보이는 테두리는 추가하지 않았다. 재료 그림 위를 밀어도 목록이
스크롤되고 담기·보관·비교 행동은 원래 버튼에서만 실행된다.

저장 형식21·소유 배합·가격 계산·궁합 공개 규칙은 그대로다. 목록은 이미 소유한
원재료와 공법만 보여 주며 시식하지 않은 레시피의 점수나 궁합을 공개하지 않는다.
