# 재료 상세에서 이어지는 메뉴 개발

선택한3번 시안의 그릇 중심 첫 화면은 유지합니다. 재료 옆 정보 아이콘을
누르면 가격·준비시간·맛의 특성과 실제 발견 조건을 작은 하단 패널에서 봅니다.
해당 재료가 열려 있으면 아래 금색 버튼으로 바로 선택합니다.

빈 토핑 칸을 미리 골랐다면 그 칸에 추가하고, 차 있는 칸을 골랐다면 그 칸을
교체합니다. 가득 찬 상태에서 정보 화면을 열면 어떤 기존 토핑을 바꿀지 먼저
선택합니다. 칸을 고르기 전에는 구성이 바뀌지 않으며 뒤로 가면 상세로 돌아옵니다.
각 칸의 실제 재료 그림·이름을 표시하고 기존 최소1개·랭크별 용량을 따릅니다.

국물은 육수/타레/향미유/공법, 면은 면/익힘/반죽 탭에서 고릅니다. 선택 표시는
컨트롤러가 수락한 실제 레시피를 따릅니다. 각 탭의 스크롤과 최근 탭을 기억하고
재료 상세를 보고 돌아와도 유지합니다. 실험 단서로 들어가면 단서가 지시한
재료 또는 공법 탭을 우선해서 엽니다.

선택은 초안에 바로 반영되며 돌아가기 버튼이 취소·원복을 뜻하지 않습니다.
상세 열기/탭 이동/교체 칸 탐색은 읽기 전용입니다. 결제·샘플 소비·시식 기록은
기존 시식 완료 처리에서만 수행합니다. 잠긴 재료는 조건을 표시하며 적용하지
못하고, 이 화면이 탐색을 자동 출발시키지 않습니다.

상세는 일반 재료440px/채집 재료560px, 교체 창은 현재 칸 수에 맞춰 높이를
정하되 사용 가능한 화면 안으로 줄입니다. 본문만 스크롤하며 뒤로/선택 버튼은
고정합니다. 가로에서는 최대680px 폭을 사용하고 열어둔 채 크기를 바꿔도
안전 여백과 배치를 다시 계산합니다. 터치 대상은44px 이상입니다.
