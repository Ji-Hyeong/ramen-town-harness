# 한 가지를 바꿔보는 메뉴 실험

2026-10-22 · Codex 단독 구현. Claude 사용 한도에 따른 이번 작업의 사용자 지시다.

## 눈으로 구별되는 한 그릇

개발·시식의 그릇은48×32 원본 도트로 국물·타레·향미유, 면 종류·익힘·반죽,
육수 공법과 실제 토핑 분량을 그린다. 김·달걀·차슈·표고·유자 등 각 고명의 모양을
구별하고 같은 고명 여러 분량도 각각 올린다. 정규 순서로 그려 토핑을 선택한
순서나 가격만 바꿔서 새로운 모습이 생기지 않는다.

이 그림은 조합의 시각적 설명이다. 보이지 않는 맛 보너스나 새 등급은 없다.
매장 안 작은12×7 영업용 그릇은 기존 그림을 유지한다. 모든 조합이 고유한
그림이라는 뜻도 아니다. 실제 맛·비용·시간의 기준은 기존 평가기다.

## 시식 → 관찰 → 다음 실험

실제 시식 결과에서 손님 반응 아래의 실험 카드를 펼친다. 향을 살리기·씹는 맛·
준비 시간 단축 중 최대 세 가지의 서로 다른 방향이다. 방금 시식한 메뉴에서
재료 한 선택이나 토핑 한 분량, 공법 한 선택만 바꾼 전후 그릇과 맛 축·원가·
준비 시간의 차이를 확인한다. 판매가·토핑 분량 수는 바꾸지 않는다.

이는 손님별 최고 점수 정답이나 자동 레시피가 아니다. 향이 높아져도 어떤 손님은
싫어할 수 있고 식감을 올리면 준비가 오래 걸릴 수 있다. 음식을 바꾸는 선택과
정확한 원가/시간 비용을 함께 보여 준다. 재료는 발견 여부, 공법은 가게 등급에
맞는 후보만 쓰고, 소비 샘플이 부족하면 해당 카드에 실제 부족 이유를 표시한다.

카드의 이동 버튼은 기존 개발 화면의 해당 재료 선택을 펼친다. 현재 작성 중인
초안·가격·돈·시식 기록은 그대로이며 레시피를 자동 적용하지 않는다. 직접
재료/공법을 고르고 기존 유료 시식을 완료해야 새 결과가 기록된다. 화면 열기와
스크롤 취소의 피드백은 기존 전체 버튼 경로를 따른다. 제조/영업/탐색 중에는
이동 버튼이 잠기고 직접 콜백도 거부한다.

선택한 연구 목표·수록 여부는 기존 연구 지도와 동일하다. 영구 발견·보상·저장
필드를 새로 만들지 않았으며 저장v12를 유지한다. 기존 경제·손님 점수·영업
수치를 변경하지 않았다. 반복 파밍 재료나 본편 분량을 늘린 단계는 아니다.
