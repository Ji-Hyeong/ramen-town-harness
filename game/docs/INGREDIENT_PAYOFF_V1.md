# 발견한 재료로 한 그릇 실험하기

2026-10-25. 채택한 메뉴 개발 시안의 프레임·글꼴을 이어 쓰는 개선입니다.
[실제 화면과 전후 비교](uiux-reset/ingredient-payoff-v1/)에서 확인할 수 있습니다.

## 조작

1. 탐색에서 직접 수령하면 재료 그림·정확한 수량·보관량·풍미를 보여 줍니다.
   공급처 발견은 영구 사용, 연구 채집은 시제품용 샘플로 구분합니다.
2. `이 재료로 개발`에서 재료 상세로 이동한 뒤 `넣기 전후 비교`를 누릅니다.
   지금 그릇과 바꾼 그릇, 풍미·원가·기본 준비 시간의 변화를 비교합니다.
3. 토핑 칸이 가득 차면 바꿀 한 칸을 직접 고릅니다. 같은 토핑도 한 분량씩
   다룹니다. 미리보기 동안에는 초안·돈·샘플·시식 기록이 바뀌지 않습니다.
4. `풍미·샘플·실험 목표`에서 전체 풍미, 분량별 필요 샘플, 궁합, 해당 재료와
   연결된 기존 연구 방향의 충족·남은 조건을 봅니다. 예상 변화이며 손님 반응은
   취향에 따라 다릅니다. 완성 레시피를 자동으로 선택하지 않습니다.
5. `초안에 반영`으로 비교한 재료 하나만 바꿉니다. 이때도 결제하지 않습니다.
   샘플이 부족해도 초안은 편집할 수 있지만 시식은 기존 재고 검사를 따릅니다.
   잠긴 재료와 현재와 같은 구성은 반영할 수 없습니다.
6. 실제 유료 시식이 끝나면 비용과 넣은 분량만큼의 샘플을 한 번 사용합니다.
   실제로 처음 완성한 연구 방향·연구 기록은 금색 발견 버튼에 표시합니다.
   눌러 조건과 보관 중인 시식 노트를 확인합니다. 같은 방향을 다시 만들거나
   재시작하면 `완성한 방향`으로 표시하며 새 발견이나 추가 보상을 만들지 않습니다.

다른 작업으로 초안이 바뀌었다면 오래된 미리보기를 적용하지 않고 다시 비교합니다.
드래그 종료로 버튼을 누르지 않는 기존 터치 동작과 고정 하단 버튼도 유지합니다.

## 범위

새 재료·지역·가격·풍미 보너스·저장 형식·영구 업적은 추가하지 않았습니다.
방향 진행도는 보관한 실제 시식 노트를 기준으로 하므로 영구 수집 도감과 다릅니다.
준비 초는 조합의 기본 시간이며 실제 연출을 그 시간 동안 기다리라는 뜻이 아닙니다.
아이폰 설치와 사람의 재미 평가는 이번 검증에 포함하지 않습니다.

UI 투영 도우미 `ingredient_trial_preview.gd`는 기존 평가·샘플·방향 조건을 읽고,
기존 guarded action으로 명시적인 한 재료 변경만 전달합니다. 도메인·저장 서비스·
원본 그림·폰트는 그대로입니다. 격리된 시험 저장의 실제 렌더링·입력·반복 시식·
재시작·부족·잠금·기존 저장 실패 회귀는 [디자인 QA](../../design-qa.md)에 기록합니다.
