# 원재료 제면: 실제 화면 기록

선택한 기존 그릇 편집기의 색·프레임·글꼴을 유지한 Mac 네이티브 렌더링이다. 새로운 시안 이미지가 아니라 실제 게임 화면이며, 세로390×844와 가로1280×800을 별도 시험 저장 공간에서 입력·캡처했다. 실제 iPhone 입력 검증으로 해석하지 않는다.

- [배합 요약](portrait_noodle_01_formula.png): 완제품을 주지 않고 개발비·시간과 네 가지 상세 입구를 보여 준다.
- [가루 상세](portrait_noodle_02_flours.png): 원재료 그림·성질·원가·선택을 분리하고 산메밀은 실제 채집 전까지 잠근다.
- [배합 변경](portrait_noodle_05_ready.png): 강력분·간수·중간면·고가수의 실제 예상 수치다. 음수 향 기여도도 숨기지 않는다.
- [반죽 작업](portrait_noodle_06_kneading.png), [밀기·숙성](portrait_noodle_08_rolling.png): 실제 경과 시간으로 움직이며 하단에서 무료 취소할 수 있다.
- [완성 목록](portrait_noodle_10_complete.png): 완료 후 비용을 한 번 내고 직접 그릇에 적용한다.
- [저장 거부](portrait_noodle_09_unsaved.png): 의도적으로 보호된 시험 저장소의 거부를 표시한다. 해제 후 직접 저장으로 같은 결과를 비용 없이 보존한다.
- [적용](portrait_noodle_11_applied.png), [실제 시식](portrait_noodle_13_tasted.png): 개발 육수와 면을 함께 넣어 시식 기록을 만든다.
- [가로 배합](desktop_noodle_05_ready.png), [가로 완성](desktop_noodle_10_complete.png), [가로 적용](desktop_noodle_11_applied.png), [가로 시식](desktop_noodle_13_tasted.png).

원본 전체 캡처, 정확한 소스 목록·해시와 패키지, 격리된 저장·로그·종료 상태는 원래 작업 공간 `outputs/ramen-raw-noodle-development-v1/final-v5`에 보관한다. 초기에 발견한 그림 조회 중 화면 이동 오류·카드 스크롤 차단·색상 상수 오류·음수 향 표시 누락은 수정했으며 실패한 실행 로그는 별도 진단 자료로 남긴다. 최종 결과는 저장소 루트 `evidence/raw-noodle-development-v1.json`과 [기능 설명](../../RAW_NOODLE_DEVELOPMENT_V1.md)에 기록한다.
