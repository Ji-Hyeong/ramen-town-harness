맞는 조건은 카드를 눌러서 읽는다. 아직 시식하지 않은 초안의 정답을 보여주지 않는다.

## 검토 범위

공개한10장을 원본 크기로 열어 제목 우선순위, 금색/중립색, 글자·테두리 여백,
누를 수 있는 영역과 가로·세로 배치를 확인했다. 자동 캡처 전체를 수동 검토한
뜻은 아니다. 시험에서 작업 시간을 앞당겼고 실제 iPhone 입력·성능·음향·
사람의 재미 수용은 검증하지 않았다.
