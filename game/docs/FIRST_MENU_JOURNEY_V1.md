# 첫 메뉴에서 다음 실험까지

홈의 기존 하단 버튼이 현재 필요한 작업으로 바뀐다. 매장을 가리는 새 안내
패널이나 강제 튜토리얼은 추가하지 않았다. 가게 운영 상세에서 초상과 함께
목표를 읽고 같은 작업으로 이동할 수도 있다.

## 실제 플레이 흐름

1. 한도윤의 기존 취향인 진하고 든든한 국물을 첫 요리의 동기로 삼는다.
   손님이 이미 방문했다거나 사연을 수락했다고 표시하지 않는다.
2. 원재료 육수와 면이 없으면 해당 제조 화면으로 간다. 이미 완성했지만
   담지 않은 개발품은 다시 결제하지 않고 완성 화면으로 돌아간다. 실제
   그릇에 담기는 동작은 사용자가 별도로 확정한다.
3. 첫 시식을 마치면 판매 준비로 간다. 이 안내를 누르는 것만으로 영업을
   시작하거나 판매 메뉴를 바꾸지 않는다. 기존 영업 시작 버튼을 사용한다.
4. 실제 정산에서는 남긴 돈과 팔린 음식을 먼저 본다. 금색 화살표 버튼을
   눌러 다음 실험의 세 가지 선택을 연다. 각 카드는 전체가 눌리는 버튼이다.
5. **맛본 메뉴 다듬기**는 카드가 인용한 손님의 실제 시식평을 연다.
   **재료 탐험**은 기존 지역 선택, **연구·성장**은 기존 연구 의뢰를 연다.
   현재 초안 유지·재료 선택·시식·출발·제출은 각각 기존 화면에서 결정한다.

## 비교의 근거

개량 시식의 ‘이번 개량의 변화’에는 기록에 보관한 실제 이전/이번 그릇과
원가·준비 시간, 달라진 맛 최대 두 축을 표시한다. 전체 점수·재료 변경은
한 단계 펼쳐서 읽는다. 이전 노트가 삭제돼도 개정 기록의 불변 복사본을
사용하며, 첫 시식에는 가짜 이전 그릇이나 0점 기준을 만들지 않는다.

연속한 두 번의 영업에는 ‘지난 영업과 비교’를 열 수 있다. 실제 완료 주문과
운영비까지 뺀 이익을 나란히 보여 준다. 날짜에 따른 수요·메뉴·직원 등 조건이
다를 수 있으므로 차이를 마지막 재료 변경의 인과적 효과라고 단정하지 않는다.
이 비교의 이전 영수증은 실행 중에만 보관한다. 재시작 후에는 과거 영수증을
현재 초안에서 추측하거나 비교 기록이 있다고 표시하지 않는다.

## 보존한 규칙과 한계

저장 스키마18, 원재료 제조, 선택 후 궁합 발견, 반복 토핑, 기존 거래·비용·
재고·샘플·영업·승급·훈련·연구 보상은 그대로다. 안내의 진행은 실제 저장
상태에서 다시 계산하며 별도 튜토리얼 원장이나 보상을 만들지 않는다.
기존 저장과 진행 중 탐색은 처음부터 다시 하도록 강제하지 않는다.

Claude는 목표 투영·클릭 카드·집중 시험을 구현하고 보정했다. Codex는 완성품
재진입 보완, 홈·시식·비교·영업·다음 목표 연결, 실제 렌더링과 독립 검증을
맡았다. 파일 작성은 순차로 진행했다. 테스트 실행은 Codex가 수행했으며
Claude의 완료 보고를 통과 증거로 쓰지 않았다.

이 작업은 초반 흐름의 구현·검증이다. 사람이 실제로 30분을 즐겁게 플레이했다는
증거, 6~10시간 본편의 분량·밸런스 완성, 새 식재료·직원 성장·골목 콘텐츠의
추가가 아니다. iPhone 설치와 최신 실기기 조작·음향·발열 확인도 포함하지 않는다.
