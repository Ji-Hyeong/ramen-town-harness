# TASK
iPhone 15 Pro를 첫 후보 기기로 iOS 빌드 환경과 재현 가능한 내보내기 준비를 한다.

## CONTEXT
사용자가 iOS 실기기 검증 준비를 승인했다. 정확한 기종/iOS 버전은 아직 미확인이다. 시작 main은 de76d58이며 Mac 실제 검증/PCK와 기존 앱·실제 저장은 보존한다. macOS26.5.2 arm64, 여유 공간193GiB, CommandLineTools만 선택돼 있고 표준 응용 프로그램 경로에 Xcode가 없다. App Store의 최신 Xcode는 macOS26.6 이상을 요구해 설치를 거부했다. 공식 호환표의 Xcode26.6은 현재 OS를 지원하므로 Apple 공식 과거 버전 경로를 확인한다.

## REQUIREMENTS
- 공식 Godot4.7.2 표준 내보내기 배포물의 SHA256/공식 SHA512를 확인하고 iOS 템플릿만 새 격리 도구 폴더에 준비한다. 기존 엔진·전역 Godot 설정은 변경하지 않는다.
- Xcode는 Apple 공식 경로만 사용한다. OS 업그레이드·기존 개발 도구 덮어쓰기·보안 우회·자동 약관 동의는 하지 않는다. 로그인이 필요하면 사용자에게 실제 남은 단계를 안내하며 독립 준비는 계속한다.
- iOS 준비용 스냅샷/프리셋을 별도 폴더에서 만들고 실제 게임 소스·Mac PCK·실제 사용자 저장을 보존한다. 프로젝트에 자격 증명/개인 Team ID/서명키/프로비저닝을 넣지 않는다.
- 실제 선택된 Xcode/SDK/서명 계정/기기 준비를 구분하고 미충족 시 성공한 서명/설치/실기기 검증을 주장하지 않는다. 서명 없는 내보내기 또는 정적 준비가 가능하면 그 결과와 한계를 기록한다.

## CONSTRAINTS
Codex가 준비·도구 구현·검증한다. 변경 범위: game/tools의 한정 iOS 준비 도구와 관련 시험, iOS 안내 문서/README/검증 기록/evidence/AGENTS 및 이 계약. 승인 없이 게임 규칙/저장 스키마/공개 Mac 앱을 변경하지 않는다. GUI 조작은 CUA로만 하고 셸에서 GUI를 띄우지 않는다. Apple 로그인·기기 연결/신뢰·약관의 최종 동의가 필요하면 구체적 화면에서 사용자의 조작/확인을 요청한다.

## ACCEPTANCE CRITERIA
검증된 iOS 템플릿과 내보내기 준비물이 있고, 실행 가능한 환경 사전 검사/부족 조건/다음 작업이 재현 가능하다. 가능한 빌드 단계까지 실제 실행하고 미완료 단계를 명확히 구분한다. 현재95개 게임 배포 소스의 바이트 보존과 기존 앱/실제 저장 비접근을 확인한다.

## VERIFICATION
공식 배포 해시·압축 경로/용량/형식, iOS 프리셋과 격리 스냅샷, 사전 검사·잘못된 입력/기존 출력 보존, 소스 해시/문서 링크를 확인한다. Xcode/SDK가 있으면 서명 없는 기기 빌드부터, 사용자 기기와 계정이 준비되면 실제 설치/저장/화면/수명 주기 검증을 별도 기록한다.

## OUTCOME (2026-10-20)
공식 템플릿의 SHA256/별도 SHA512/목록 파일 digest·iOS arm64 라이브러리와 실제 격리 임포트/엄격 서명을 확인했다. 기본 staging은 성공했고 원본95개 게임 소스/Mac PCK가 그대로다. 실제 Godot 설정12확인과 도구 안전성9시험이 통과했으며 기존 출력·실제 팀 없는 내보내기는 실제 CLI 종료2로 안전하게 거부했다. [안내](../game/docs/IOS_DEVICE_PREPARATION.md), [증거](../evidence/ios-device-preparation-v1.json).

Xcode 설치는 Apple 공식 호환 버전 다운로드의 사용자 로그인에 막혀 있다. 현재 최신 App Store 버전은 OS 호환성으로 거부됐으며 Mac OS를 임의로 바꾸지 않았다. Chrome 공식 로그인 페이지를 보존하고 사용자 입력을 요청했다. Xcode/SDK/서명·프로젝트 내보내기/iOS 앱/실제 기기 검증은 이 준비 결과로 완료 처리하지 않는다. 로그인 후 남은 환경 작업을 이어가며 실제 기기 연결 전 독립 준비를 최대한 완료한다.
