# TASK
새벽 장터의 반복 채집→연구 재료→시제품→실제 판매를 연결하는 작은 기능을 구현한다.

## CONTEXT
사용자는 라멘집1곳/고정 부지 골목/본편6~10시간+자유 운영을 선택했고, 재료 파밍과 재료별 다양한 결과물을 포함하는 메뉴 개발을 최우선으로 요청했다. 다음 작업 진행을 지시했다. 현재 공급처 탐색은 완료 후 닫혀 반복 실험 재료를 주지 않는다. 공개 main d068d8e에서 새 기능 브랜치를 만든 뒤 로컬 범위 문서6d0f868을 FF로 보존했다.

## REQUIREMENTS
- 기존 장터 공급처2개를 발견한 뒤 열리는 별도 반복 채집을 추가한다. 기존3지역의 발견/비용/영수증은 그대로 보존한다. 채집과 기존 탐색을 합쳐 하루 출발1회이며 포기해도 환불/출발권 복구가 없다.
- 장터에서 두 번 선택해 볶은 참깨유/유자 껍질 두 연구 재료 중 하나를2개 또는 추가 비용으로3개 얻는다. 출발1,000원/추가300원, 재료별 보관20개. 결과를 받을 때만 한 번 지급하며 보관 초과는 선택 전에 거부한다. 이동 연출과 기존 잠금·실패 안내를 재사용한다.
- 새 재료는 처음 수령 후 선택할 수 있고 시제품 완성 시 구성에 든 새 재료를 각1개 소비한다. 취소·중복·잘못된 시식·자금/용량 부족은 재료·돈·기록을 모두 보존한다. 기본/기존 발견 재료는 계속 영구 공급한다.
- 시식해 등록한 메뉴의 영업은 샘플 재고를 추가 소모하지 않으며 기존 영업 원가로 공급한다. 이를 획득·개발·영업 화면에서 명확히 설명한다. 재고0이어도 이미 만든 메뉴를 판매할 수 있다.
- 새 두 재료의 맛/원가/준비시간·궁합·그릇 도트를 구분한다. 기존 재료만 쓴 평가/영업/그림을 보존하고 무작위 재추첨·품질/산지/새 등급/골목 콘텐츠는 추가하지 않는다.
- 저장11에 채집 진행/재고/획득·소비 합계/첫 획득/최근 영수증을 보존한다.1~10은 빈 채집으로만 이행하며 실제 구10 파일 백업·전체 기존값을 확인한다. 손상 상태는 원자 거부하고 모든 단계 재시작·저장 실패/복구·중복 지급을 검증한다.
